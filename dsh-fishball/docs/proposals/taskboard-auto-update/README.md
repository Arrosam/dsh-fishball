# 让任务板跟上会话，而不是让会话替人结案

**任务 A · 待评审设计，不是已上线功能。** 只讨论 Fishball 的可编辑任务板。用户说：“在会话返回后，经由一个弱模型去更新task board，如果触发了更新，再一并告知fishball被更新的task的进度及其附属的主task。”以及“这个弱模型也要可以选择”。目标是即使工作模型忘记调任务工具，有证据的进度也能上板；不是让另一个模型管理会话。

## 走一遍：从打开开关到撤销

1. **先选择由谁读这些数据。** 在任务板设置打开“自动更新”。未选模型就是关闭：不订阅新工作、不计费、不追补。打开开关先选本机 DSH 目录中的具体供应商/模型，选定并成功保存后才生效；选空或关掉即清空该选择。没有第二个可能与选择矛盾的持久开关。此选择**不改** Fishball 自己、启动受管会话或 DSH 的默认模型。目录加载中禁选，读取失败可重新打开设置；已选型号消失则保留失效选择、暂停并提示重新选，不回退到昂贵模型。保存失败仍以原值为准。
2. **知道何时会花钱。** 开启意味着同意把受管会话本轮最后一条助手文字和当前任务树（ID、直接父 ID、标题、状态、进度、备注）发给所选供应商。备忘录、其他会话、历史对话、工具结果、附件、权限信息及凭据不是输入。备注/最终消息本身也可能含敏感信息；不愿发送就保持关闭。规则区解释能写什么、不能写什么以及预算，不是可编辑系统提示词。换模型或关闭后，在途结果作废；已发出的请求不能撤回，已消耗的用量不能退回。旧记录和撤销入口继续可用。
3. **让一个受管会话返回。** 安装文档会话 `ses_docs_7f2a` 报告离线步骤写到 70%，命令验证进行到 40%，校验值已核对。以本轮、完整且可归属的报告为准；不能确定归属就不分析。不是按每个助手回复、每个子代理退出或每次页面刷新触发。后台预览服务可以仍在运行。插件在原有事件投递之外分析，不等弱模型才能继续跟用户说话。普通 Fishball 处理工作会话的职责不变。
4. **看懂模型能决定什么。** 模型只提议“哪个已有任务、改哪些字段、对应哪段原话”。允许空结果。报告能唯一定位同一标题/路径或明确 ID，且支持该字段的具体变化才可采用。提议必须用快照里的 ID，不按相似度挑第一名。无任务、同名消歧失败、“不错”“大致快完了”、方向不明的数字都不是进度证据；不创造百分比。模型没有工具、存储、发消息或改配置的权限。将板和回复都当数据，不执行里面夹带的指令。
5. **看板先提交，通知后发送。** 示例两条有效变化作为一个批次：**补写离线安装步骤**从 30% 到 70%，保留已有备注并追加有据片段；**验证离线安装命令**从待办 0% 到进行中 40%。父任务**发布安装指南**仍是 45%——子项不会拉高父项。板从 v17 到 v18，更新行带文字标识，颜色不是唯一线索。板头“完成”统计仍按原规则计数，不拿子项算术平均代替。可展开父任务或打开更新记录定位这个批次。
6. **Fishball 收一条，而不是每一行一条。** 内容来自提交后的板，不是照抄模型输出。例：**会话 ses_docs_7f2a · v18**；补写离线安装步骤 **70%**（上级 发布安装指南 **45%**）；验证离线安装命令 **40%**（上级 发布安装指南 **45%**）。即使只改备注也列该任务当时的进度；顶层项写“无父任务”，多层显示根到直接父的路径。另列本批关联的“校验值待复核”，不算第三条已更新。此条发给 Fishball，而非冒充用户编辑。用户看到的是任务行及记录；不默认复制到聊天、桌面推送或外部频道。Fishball 如有本来就该报告的工作成果，照旧报告，不复读整条通知。收到自动更新通知也不据此再写一次同样的值。
7. **单独判断“做完了”。** 校验项保留原来的进行中、90%；不偷偷写成 done、100% 或 99%。只要该项的提议指向完成，就整项留作复核，不把它的其它字段悄悄提交。Fishball 可以在看板读取中看到待复核项、来源和依据；读到旗标并非接受建议。只剩一个待复核项时，记录旗标但不唤醒 Fishball，不算改了任务。确有证据才由 Fishball 主动复核，有分歧就维持原值；**只有确需人作决定**才通过 PTC 的非阻塞 `ask_user` 卡询问，不把每次复核变成人工审批。卡未回答时，不停住别的工作、不据此结案。版本已变须重读，不能拿旧审批压过新值。
8. **从哪看、怎么退。** 在板上点自动更新标记或“更新记录”，看会话、模型、版本、每个字段的前后值、关联父项、复核状态和通知投递情况。“撤销本批”只对仍可安全反转的批次可用：点前核对要恢复的两行，在提交时再校验版本，写入一次反向变化（v19），不倒退版本、不删除历史。待复核记录不是自动改掉的任务值。重复点不再生效；有人已编辑则拒绝，提示对照差异手工处理，不抢回别人的修改。撤销是用户主动操作，不再触发弱模型。
9. **遇到别人也在改。** 弱模型在 v17 开始推理；Fishball 先改了一行到 v18：整批放弃，板上保留 v18，无半批、无通知，也不花钱重新推理。反过来，若用户正持有 v17 编辑草稿，自动更新先提交 v18，原来编辑器的冲突横幅和 409 行为照旧，保留输入直到用户自己重新加载/放弃。新一轮应以新板为准，不从遗留提议生效。
10. **检查“没有新消息”是否正常。** 去“未写入”区分未选模型、模型失败、并发冲突和策略跳过。无匹配或全都与板相同是正常静默，无弹窗，无用户/Fishball 通知；可在诊断看到汇总计数。超时、供应商限流、无效返回也不改板、不回退到其它模型，不自动重跑。下次新的合格会话可重新评估；若是配置错误，先回设置修正。模型成功但通知投递失败则正相反：**板已改**，保留审计与撤销，不能显示为“未写入”或重新应用差异。

## 界面控件：每个操作改变什么

| 入口 / 控件 | 行为 | 不会做什么 |
|---|---|---|
| 设置 · 自动更新 / 更新模型 | 打开选择器，按供应商区分同名模型。保存具体型号才启用；关闭或选空清除配置。 | 不用默认模型顶替，不修改工作会话选型。 |
| 设置 · 写入规则 / 调用预算 | 只读，启用前可查看。 | 不接受自定义指令或绕过上限。 |
| 任务板 · 自动更新标记 / 已更新项数 | 查看这次提交、证据及逐字段对比。已有编辑、展开、备忘入口保持原义。 | 查看不重算、不发通知。 |
| 任务板 · 待复核 | 用户看建议和原值；Fishball 下次正常读板可见，依据不足维持原状。 | 用户打开详情并不等于确认完成。 |
| 批次详情 · 撤销此批 | 先展示受影响行；仅在服务端版本与批状态仍匹配时整批反向提交。 | 不倒带整张板，不覆盖后续修改。 |
| 未写入 · 检查更新设置 | 返回本功能的模型/规则页，按原因修正配置。 | 不重跑旧事件。 |

## 默认规则（本次请评审，不是现有常量）

| 问题 | 建议约束与可观察结果 |
|---|---|
| 允许哪些变化？ | 仅现有未结任务；状态限待办、进行中、受阻。进度仅有明示依据的非倒退整数，0–99；100 或完成转待审，撤销/退回由人处理。不自动 dropped、重开、创建、删除、改标题、改父子、挪顺序或写 memo。备注仅追加非重复、有出处的短片段；写后须符合现行 2,000 码点限制，不截掉用户原文。 |
| 20 是上限吗？ | **是自动分析预算，不是任务板存储上限**。整棵树按行数，含父项与已关闭项；0 或没有未结项不调用，1–20 可分析，21 起不调用。不能取前 20 假装全板，也不改变现有 500 个任务的写入上限。 |
| 如何控制用量？ | 建议每板同一时刻最多 1 次推理、滚动一小时最多 6 次**已发出**的调用（失败也计）；忙/无额度就跳过，不排无限队列。单次输入含规则与整树最多 8,192 token、输出最多 1,024，且不得超所选模型窗口；无法安全计量、装不下或生成不全就不提交。请求限时 30 秒，默认 0 次自动重试。429 尊重供应商冷却；显示计数/用量而不虚报精确金额。 |
| 如果模型猜错/返回坏数据？ | 仅接收带精确 ID、字段白名单和本轮依据的结构化批次；拒绝未知/重复 ID、未知键、越界、无来源或截断的建议，不接收工具调用、脚本、整板替换。整批校验失败时不部分应用；经验证的完成候选分流到复核，不等同格式错误。语义误判仍可能通过，所以要有来源、审计和撤销。 |
| 重复或过期事件？ | 按可信目标 + endpoint epoch + eventId 去重，**不是仅按 session id**。同一会话下一条新事件可正常评估。取回会话、目标替换、事件倒序、配置变化时丢弃过期结果。自动更新、通知、Fishball 本机回合、模型调用、审计、撤销都不是该输入事件。不订阅板变化来启动分析。 |

## 请拍板的边界

- **“主 task”指哪一级？** 建议直接父项的已存进度；深层给出根到父的路径以便定位。如更想看顶层目标的进度，可额外显示，不能把二者混称。
- **仅有完成线索时，要不要专门叫醒 Fishball？** 建议不叫醒：下次读板即可复核，符合“没有任务实际变化就静默”。代价是复核可能不即时。
- **严格 20 项 / 6 次每小时 / 30 秒是否适合真实负载？** 建议先按上表；较大的板宁可跳过，不把不完整上下文交给弱模型。放宽前先看跳过次数和费用。
- **撤销要不要跨越一次无关编辑？** 首版建议不要：整板版本门槛容易解释，也不会覆盖后来工作。代价是两次互不相关的编辑也可能使一键撤销失效。
- **保留多少本地历史？** 建议已结束批次最多保留最近 30 天；到期不再提供撤销，明确显示保留期限。未解决复核与未确认投递不能按日期直接删除；去重凭据须覆盖上游可重放期。审计保留必要的板差异和短依据，不保存完整模型提示、回复全文或密钥。

**不在范围内：** 其他项目的顾问/触发器、对话转发或自动追问、连接新供应商、模型管理、外部推送、自动规划/拆解任务、绑定会话到任务、百分比汇总、数据库实现及插件安装。不会借另一项目的文件、键、工具或事件。未批准前不改产品代码或已批准的总体设计。
