# Native owner action preview

Status: Stage3 implemented boundary under module review; native composition pending. This narrows the authenticated native owner's grant path, while the authoritative store remains the grant/claim authority.

`v1/preview` input is `{taskRef,actionRef,actionDigest,recordRef,expectedTaskVersion,expectedAuthEpoch}`. The server reads the exact immutable scoped action and authenticated encrypted data, verifies the full data digest, current task/control/model/resource policy, and calls a trusted installation-only resolver for concrete target/model/reasoning/preset/tool/environment meaning. Missing meaning or stale provenance fails closed; RPC cannot supply verified flags, labels, raw handles or keys.

Response is `{previewRef,taskRef,actionRef,actionDigest,taskVersion,authEpoch,expiresAt,description}`. Description contains `{kind,role,targetLabel,data:{recordRef,digest,kind,content},model:{provider,model,reasoning,preset},toolNames,environment:{label,cwd,environmentRef},limits:{units,attemptIndex,charges},evidenceRef}`. The displayed data is the exact approved record content, not an unbound summary. Known secrets are rejected. Concrete labels are host-derived, not inferred from hash strings. Charges preserve unknown cost rather than fabricate zero. Preview TTL must be explicitly supplied by trusted installation, structurally capped at60seconds; no product approval-duration default is selected.

`v1/grant` requires normal exact action/task/auth CAS, explicit grant `expiresAt`, plus the captured `previewRef`. The server rechecks current data/action/policy and re-resolves current meaning after asynchronous callbacks, consumes the preview and calls the atomic authoritative grant. An unissued, foreign-instance, stale or expired preview reference, mutation/revoke/disconnect/unload, changed model/catalog/environment/tool meaning or changed data rejects. Grant expiry is the owner's explicit choice; it is distinct from the preview lifetime. A grant never starts model work automatically.

The native client requests a fresh preview and displays the concrete scope before enabling approval. Unknown/unavailable concrete meaning keeps approval disabled. UI state/reconnect races invalidate captured material. The process-private cache is bounded64, evicts expired entries only, loses validity on unload/restart and supplies no durable authority. Duplicate grant uncertainty must use authoritative status/receipts, never mint a new preview and claim a prior outcome.

Preview references are copyable JSON strings recognized only by their originating private instance; copying one grants no operator identity. Pending resolver work reserves the same64-slot bound before any await, and one resolver may grant against each preview at a time. Callback exceptions always map to a fixed error; exported error class instances cannot supply public codes. Clock rollback fails closed.
