# NI2 normal installed worker contract — draft for freeze

Status: **AUTHOR CONTRACT DRAFT; no implementation GO, independent design freeze, CODE verdict or native acceptance.** Prepared against the root-reported clean documentation baseline `d91d749` on `feat/S3-integrations`. Root owns Git and the eventual contract freeze. This draft implements the direction in [the normal worker proposal](normal-worker-proposal.md), [the required normal stages](normal-entry-integration-plan.md) and [the NI1 checkpoint](evidence/NI1/checkpoint.md). It does not change their historical evidence. Author/source observations are recorded separately in [NI2 author notes](evidence/NI2/contract-author-notes.md).

NI2 is the normal installed path from a current owner task/context to one idle original native worker, one explicitly approved synthetic native request, a captured encrypted local result and an explicit factual finish. An advanced callback factory is not the normal interface. Defaults are disabled. Real providers/inference, tool bodies, external recipients/accounts/credentials and publication remain unauthorized. Final independent CODE, browser/rendering, model quality, full source-AC/MVP/release acceptance remain HOLD. No blocked review or browser mechanism is retried or rerouted.

## 1. Exact installed-only configuration

Extend only installed Config with optional `worker`. Omission and exactly `{enabled:false}` normalize to the same immutable disabled object. Disabled rejects every other field. The original base Config and the existing advanced runtime factory meanings remain unchanged. Enabled requires literal `true`, enabled NI1 memory/context and every field below; there are no example-derived defaults.

```js
worker: {
  enabled: true,
  selection: {
    provider: 'df-testing-local',
    model: 'df-testing-worker-v1',
    agentPreset: 'owner-selected-empty-preset',
    reasoningEffort: null,
    maxOutputTokens: 128
  },
  environment: { root: '/canonical/owned/workspace', cwd: '/canonical/owned/workspace' },
  persistence: {
    directory: '/canonical/profile/df-owned/df-sessions',
    compression: 'none',
    retention: 'owner-managed'
  },
  bounds: { requestBytes: 131072, resultBytes: 16384 },
  policy: { maxRuntimeMs: 60000, maxUsageUnits: 135168, maxCostEstimateMicros: 0 },
  charges: { runtimeMs: 10000, usageUnits: 131200 },
  previewTtlMs: 30000,
  grantTtlMs: 60000
}
```

The example identifies the optional synthetic provider described below; it is neither a production model selection nor authority. Enabled worker additionally requires explicit base `limits.maxMetadataBytes:4096` (the existing base ceiling) so a complete normalized action/control receipt fits without truncation or a silent increase of the owner's limit. All objects are closed, detached and recursively immutable. Worker records require ordinary Object prototypes and own enumerable data properties; reject proxies, accessors, symbols, hidden fields, unusual prototypes, missing fields, truthy booleans, nonfinite/fractional/unsafe integers and unknown keys before reading their values. Preserve existing top-level/base/NI1 validation behavior when worker is absent.

| Field | Exact domain and meaning |
| --- | --- |

| selection.agentPreset/reasoningEffort | Preset string uses the same string rules with 128-byte ceiling. Reasoning is required `null` or a nonempty 128-byte effort string. Null proposes omission; actual materialized native defaults must be resolved and displayed. |

Installed NI2 fixes `maxActive=1`, `maxAttempts=1`, `maxTotalAttempts=1`, and `units=1`. Keep the base queue bound. Only a product-derived initial `kind:'write', role:'worker', executor.mode:'create'` action is admissible. Resume, repair, review, messages, delivery and other actions do not acquire authority from NI2. NI3 may later expand its explicit bounded total policy under a separate contract; NI2 cannot silently raise capacity for it.

Initial create-only is the first bounded NI2 implementation unit, not removal of required normal continued work. Before aggregate completion, a separately frozen additive NI2 resume contract and independent design must provide exact signed old owned session mapping, a new explicit generation/action/grant, original idle resume with zero streams, preview and admission of bounded actual retained history plus current instructions, and refusal of cross-task/unowned history or automatic wake. Existing advanced resume remains unchanged. The owner already authorized this continuation; it requires no renewed permission. NI6 retains resume as pending until executable and actual native package evidence exists.
