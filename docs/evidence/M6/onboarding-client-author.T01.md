## Remediation boundary

The shared task-model `call` now requires a **literal `ok:true`**, own `value` field and closed success envelope with no `error` or unknown fields. A literal `ok:false` requires a closed error envelope with own string `code`, optional string `message` and optional plain-object `details`; only a known stable error code is retained. Unknown error codes remain `RESULT_UNCONFIRMED`. Missing/malformed/contradictory/unknown envelope fields fail with `INVALID_RESPONSE`. Both the404 and405 fallback still require a fresh successful task-list snapshot, and the setup route still cannot confer task/action/setup authority.

Before endpoint handlers read reply values, a descriptor-based plain JSON walk rejects getters/accessors, symbols, hidden fields, inherited/custom prototypes, sparse arrays, non-JSON values and cycles. It reads descriptor data rather than ordinary accessor properties. It then uses the existing browser `structuredClone` API to create the safe detached reply and reject otherwise transparent Proxy values. The existing factory already uses this API for other task data; task RPC parsing now also requires it. Missing or failing structuredClone rejects safely with `INVALID_RESPONSE`, rather than falling back to unsafe direct reads. Endpoint field/size/semantic validators remain unchanged; no new product payload, permission or policy limit was added.

Thrown RPC failures are converted to stable errors by safely inspecting an own data `message` descriptor. Raw thrown prose, inherited messages and accessor messages are not exposed. Current connection epoch and abort state are checked before parsing; ordinary pending/stale/disconnect/disposal/uncertain-result behavior remains intact. Valid original native success/error reply formats and frozen plain JSON replies remain accepted. The bundle was rebuilt through the existing deterministic emitter.

A hostile same-process Proxy can execute reflection traps while descriptors/prototype are inspected; browser JavaScript cannot universally suppress those traps without a different trust boundary. The implementation does not invoke ordinary getters. Transparent Proxy values are rejected by structuredClone, and throwing reflection traps fail safely with redacted stable errors. Author tests explicitly observe one hostile `ownKeys` trap, then verify `INVALID_RESPONSE` and absence of its canary. They do not claim all trap counts are zero. Native JSON RPC bytes cannot contain executable accessor or Proxy code; these typed malformed objects are additional module-safety cases. No native/private dependency workaround was added.
