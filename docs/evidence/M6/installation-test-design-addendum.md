The new module API is `SetupState({databasePath, profile:{dir,name}, limits?, isAlive?, currentProfile?, clock?, activate, observeCommit?})`, `status({})`, `prepare({})`, asynchronous `confirm({previewRef,planDigest,accept:true},{signal?})`, asynchronous `resume()`, and `dispose()`. This is a trusted same-process constructor seam, not Config/RPC authority. `activate` receives the private generated identity and32byte key through the closed composition; transient buffers clear after copies. `observeCommit` is only an authorized enum-only process barrier/exit seam; no path, key, handle, store, grant or admission override is exposed. Proposed cuts are `namespace_claimed`, `staging_closed`, `database_published`, `key_published`, `metadata_published`, `runtime_ready`. Source remains work in progress until its author freeze; these API notes are test design, not executed acceptance.

Concrete stated bounds: RPC1024bytes, metadata4096bytes, path1024characters/depth16, references64lowercasehex, preview at most60000ms with exact expiry equality and clock rollback denial, key32bytes, private files0600/nlink1 and namespace0700. Verify N-1/N/N+1 with the actual held implementation's chosen byte/character serialization measure; do not confuse the client4096UTF8 display bound with the narrower server path bound. Errors use only `SETUP_REQUIRED`, `SETUP_RECOVERY_REQUIRED`, `SETUP_UNAVAILABLE`, `SETUP_PREVIEW_STALE`, `SETUP_CONFIRMATION_REQUIRED`, `SETUP_INVALID_INPUT`, `OPERATOR_REQUIRED`, `REQUEST_ABORTED`, `SERVICE_DISPOSED` as appropriate; the actual snapshot/effect oracle is authoritative.

Normal owned native profile directories/ancestors may legitimately be0755, provided the applicable owned profile tree is not group/other writable. The new private vault must be0700 and sensitive files0600; pre-consent load/status cannot chmod the existing profile to satisfy a synthetic700-only fixture. OS root ancestors are not required to share current user UID. Tests must include legitimate native0755profiles plus writable/foreign-owned/link negatives, using only new synthetic paths, rather than falsely proving normal installation from uniformly private fixture ancestors. Bound canonical `profileContext.dir`, profile/name/current identity and inode are derived from the public native carrier, never JSON claims.

Public Cordis startup state1 may be used only for internal resume/activation composition; externally admitted RPC requires active state2. Own closing/disposed states cannot confirm or dispatch. Borrowed mutation checks use this actual closure fence. Readonly diagnostic observations during an ancestor cleanup callback are distinct from task admission after own closure; no instant cancellation promise is added.
