No implementation edits or execution follow that candidate in this proposal.

The designer's observation establishes a client validation gap, not a server return mismatch. Current `createNormalModel.run()` checks the automation top level and only eight selected slot scalar fields; it accepts extra slot keys and leaves clock, reason, pending approval and occurrence data unvalidated. Features memory is not parsed; memoryRead checks only namespace/revision and an array-shaped facts value. memoryStatus and memoryCommandStatus fall through to generic reply display, and memory preview descriptions are not closed. The actual original server returns finite typed shapes. No parser may reject an actual valid original domain merely to produce a convenient finite enum.
