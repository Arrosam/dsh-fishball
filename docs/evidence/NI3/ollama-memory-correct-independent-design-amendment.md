## New public seam and its limits

The concrete installed entry retains createApprovedInstalledPlugin({cloudAdmission}={}), its original Config/name/inject and existing provider/worker/stream signatures. It composes original createInstalledMemoryContinuity only for an installed worker with memory. There is no injectable runtime factory, arbitrary store/projection handle, owner/coordinator capability or new wire-capture mode.

The single new endpoint is /df-rpc/v1/memoryCorrect through the original authenticated operator bridge. Original Connection supplies admitted operator and assertCurrent; wire JSON supplies no principal, namespace, callback or currentness substitute. It is available only in the new concrete worker+memory composition. Existing memoryRead/memoryRemember/prepareContext remain; continuity status/import/export/delete/forget are not exposed. The abstract original54 memory operations list is not proof that those additional continuity endpoints exist in this concrete capsule. This amendment uses memoryRead and the original correction receipt for observations, rather than assuming a new memoryStatus endpoint.

The exact request has commandRef, expectedRevision, id, expectedFactRevision, candidate and accept:true. commandRef is lowercase64hex; expectedRevision is a nonnegative safe integer; id and expectedFactRevision are positive safe integers. The unchanged OriginalMemoryCandidate allows preference content{text} or world content{question,answer}, confidence in [0,1], nonempty unique sourceRefs of <=16 lowercase64hex refs, observedAt nonnegative safe integer and the existing optional ttl/world-only tier/embedding/conflictRefs. At this unchanged operator bridge, wire confidence is integer0 or1 only: 0.5 is rejected before original memory mutation. The live R02/R04 candidate uses1. Do not widen the bridge, inject a factory or use a raw runtime handle to make fractional confidence pass.

Correction success is original memory metadata/CAS with actual namespace, revision, digest, recordRef, sourceRefs, timestamps, byteLength, cryptoVersion2, requestDigest and result{id,factRevision,authority:memory_only}. Names/optional fields must be pinned to the genuine original receipt schema during fixture review; no handmade receipt/envelope is a proof. Existing optional deduplicated semantics are not a new automatic retry permission. Failures use the unchanged original operator RPC protocol and listed public codes, otherwise OPERATION_REJECTED; do not invent an expanded error enum. Lifetime is original installed fiber, with continuity disposal before the same original store closes.

The installed-worker observer does not recognize memoryCorrect and proactive prepared-cache invalidation is not claimed. A retained old prepared record must remain subject to original execution-material namespace/revision and semantic/task authorization checks at beginContextExecution/assertNativeRequestCurrent. The oracle is refusal before provider inference because original material is stale, not a guessed cache deletion or fake invalidation event. Runtime proof is not supplied by this contract.
