## Independent semantic oracle

The original public plan normalizes the module-derived full spec and derives actionDigest from `{ownerRef,workspaceRef,taskRef,taskVersion,authEpoch,spec}` using the pre-plan trusted scope/CAS state. Its literal return is `{actionRef,actionDigest,taskVersion,authEpoch}`. The new module first validates the returned digest ref, then uses its existing synchronous scoped snapshot helper. It admits only the exact derived actionRef with the original returned digest and canonically identical full normalized spec.

A spec-only digest is a different value. The fixture must not rewrite either digest, normalize the public result, accept two digest forms, fabricate producer metadata, inject a private plan, or use a caller-provided proof. In the positive case the bound callbacks return literal original core values; recording an observation is allowed, replacing the source shape is not. Fault cases deliberately change a detached callback projection and are identified as typed seam faults, with the underlying core unchanged.

The genuine post-plan snapshot may have a different current task version from the planning version. Compare the action’s plannedTaskVersion/plannedAuthEpoch and the independently captured pre-plan state; do not require current snapshot version to equal the original expected version or returned planning metadata. The amendment proves association of a committed plan, not a new atomic transaction or fresh grant. An intervening source/task mutation that invalidates later execution remains governed by the existing later gates. This fixture adds no task-control mutation to simulate that wider path.

The new read is synchronous. The three race partitions therefore place a controlled currentness denial before the actual plan, after the actual plan before the new read, and inside the new snapshot callback before its return. They do not invent an await, replace a real source guard, or reverse a denial. The existing original carrier must preserve REQUEST_ABORTED; matching data never overrides it.
