# NI5 private artifact read projection

Status: source-backed additive API refinement candidate; preserve the held NI5 contract and design hashes. This note does not claim core/schema5/schema6, installed host or recipient acceptance.

The new module consumes the private closure `readArtifact({taskRef,artifactRef,version,digest})` returning a closed top-level `{artifact,data}`. Root's later closure binds the typed normal-only `RuntimeStore.readLocalArtifact(owner,input)` operation; it does not change the generic advanced RuntimeStore.artifact/readData API or reinterpret old stored schema4 verification. `artifact` is actual scoped RuntimeStore.artifact metadata for that immutable version plus the normal-only computed verificationBinding defined below. `data` is the actual permitted RuntimeStore.readData result for its recordRef, with recordRef,kind,digest,byteLength,content checked against that artifact. Kind must be artifact; byteLength must equal complete UTF8 content bytes; SHA256(content) must equal the exact artifact digest. No owner-provided body, paths, proof, role or permission flags enter this closure. Planning/publication/report selection separately compares the current latest artifact metadata; historical authenticated reads do not erase earlier version facts. Lifetime/current native peer/profile and scope are rechecked after asynchronous publication and before returning accessible publication facts.

Root confirmed that no held incompatible return shape exists. Root's later installer validates the original pinned public HostConnectionService/OperatorPeer source/class before passing ctx; this standalone module captures that original operator object, connection, verified profile and private lifetime predicate. Typed test carriers do not establish public class/native/package provenance.

The current schema4 artifact verification contains only verdict,evidenceRef,reviewerRef,generationRef. Accepted alone cannot establish normal readiness. Core/root propose the normal-only readonly computed `artifact.verificationBinding` projection with exactly the held localReport verificationBinding alternatives: null, unavailable (`source:'unavailable',verdict,reason:'PROVENANCE_UNAVAILABLE',evidenceRef`) or native (`source:'native',auditRef,auditRevision,round,reportRef,bindingDigest,materialDigest,resultRef,recordRef,digest,claimRef,generationRef,sessionRef,executionRef,inputDigest,reviewerRef,verdict,evidenceRef`). Core authenticates the actual NI3 signed audit_result/current report/exact artifact association, material/semantic coverage and producer/reviewer independence; a caller cannot provide this field as proof. Missing/unavailable/rejected/unknown provenance must refuse normal planning, preview and accepted normal notification. The atomic normal claim/publication recomputes this same source chain, rather than trusting the facade's readonly projection. This precise computed projection requires root/independent addendum binding before the affected source is held; no held NI3 document is changed.

`publishLocalDelivery` returns exactly the existing getDelivery projection: `{deliveryRef,artifactRef,artifactVersion,digest,recipientRef,channelRef,targetDigest,intent,previousDeliveryRef,state,claimRef,reservationRef,generationRef,observations,currentAccess,notification?}`. TaskRef is retained inside intent; no new required top-level taskRef is invented. Its sent observation is exactly `{state:'sent',evidenceRef,permissionState:'allowed',openability:'unknown',observedAt}` and currentAccess is exactly `{permissionState:'allowed',openability:'unknown'}`. Notification, when present, remains the original complete immutable notification binding. No extra native evidence/verification field is added to this returned delivery projection. The facade repeats actual getDelivery after await, requires the committed sent observation and exact source evidence/time/allowed permission/unknown opening, and rechecks authenticated byte availability. A callback echo without the committed association never establishes sent. Query is read-only and returns source-confirmed historical facts. Access uses the separately frozen typed current-access operation; a scoped read's actual UNAUTHORIZED/PERMISSION_DENIED can establish denied current access, while STORAGE_INVALID, CRYPTO_*, DIGEST_MISMATCH, binding/record-missing/SERVICE_DISPOSED and other storage/lifetime errors remain errors or uncertainty and never become denial proof or synthesized failure/delivery. Historical delivery remains unchanged.
