## Exact decision boundary

```js
RuntimeStore.claimLocalDelivery(handle, {
  taskRef, actionRef, actionDigest, commandRef,
  expectedTaskVersion, expectedAuthEpoch,
  delivery: {deliveryRef}
})
// -> {claimRef,reservationRef,actionRef,actionDigest,
//     generationRef,sessionRef,task}
```

Exactly seven top-level input keys and one nested delivery key; exactly seven return keys. Preserve original opaque identity/role authorization. No caller normal flag, outbox, auditRepair, callback or proof is accepted. The private normal ResultPipeline binds its existing claimAction slot to this typed method; advanced composition stays bound to original claimAction.

Both routes use one synchronous original claim transaction. Typed local checks full accepted action/delivery/native material/current task/auth/grant/expiry/control/policy/permission and complete canonical UTF8 charge **before any** attempt/reservation/worker/outbox/group/fact/window mutation. Original shared limits remain. Normal monetary zero requires actual private source-owned local route; none mode or caller zero/unknown pricing confers no authority. Claim commits before send.

The fixed typed operation name is `claimLocalDelivery`; generic remains `claimAction`. Exact original typed receipt replay acknowledges the same claim with zero new mutations. A same keyed command ID crossing namespaces conflicts in both orders; it does not reinterpret old generic bytes as typed provenance. Shared original before_commit/after_claim boundaries remain. Sticky signed normal-policy manifest/source/byte predicates also apply through generic claim. Unmarked advanced none remains compatible.

Publication repeats full native/currentness/bytes/permission checks under its original transaction regardless of claim route. It uses the same already-committed claim/reservation/outbox/group/fact/window ownership, never a second frequency/resource admission. Original getDelivery shape and sent/opening-unknown meaning remain unchanged; actual durable association, not callback echo, proves publication.

The unchanged byte recipe is full `canonical({taskRef,deliveryRef,artifactRef,artifactVersion,digest,recipientRef,channelRef,content})`. For actual byte count B and approved usage U, B<=U is inclusive only if all other predicates pass; B=U+1 refuses without truncation. At pre-claim refusal the write counters stay zero. After an already committed claim, publication refusal retains its hold but creates zero sent state. Source-owned byte units remain distinct from provider billing/runtime measurements.

Report sourceStates contains only actual requirements for the selected artifactRef, including applicable historical/current version, native report/material/finding/round/repair facts. Keep stale>blocked>budget_limited>unexamined>unknown>failed>not_run>passed precedence. Selected source rebind/round/material/verification or actual semantic/protected-context drift invalidates currentness; an unrelated B audit with unchanged semantic authority does not. Whole-task required audits and B's exact current native review covering every selected goal/statement/blocker binding still run at claim and publication.
