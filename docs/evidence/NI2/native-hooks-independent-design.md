# NI2 independent native-hook functional execution design

Executor: `/root/native_functional`, separate from the product author and the
independent provider/foundation lanes. This is functional/ISTQB execution, not
CODE review. Root delegated this exact held subunit and authorized original-public
no-listener deterministic fixtures. No CLI, profile process, listener, HTTP,
browser, external inference/tool/account/credential operation or Git mutation is
part of this lease.

validator, authenticated commands/client flow, physical original CLI/package,
resume/continuity, CODE, supported browser/accessibility, selected real-model

fixtures cannot clear those gates or establish real tokens/billing, external
delivery, exactly-once effects or immediate cancellation.
