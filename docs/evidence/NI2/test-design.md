## Contract challenges grounded in the current public source

These are design challenges and source observations, not executed product defects. They were sent to root and the contract author before implementation.

1. `AgentLoop.prepareRequest` awaits the public `agent/request` waterfall and `LlmRuntime.prepareCall` after native send. `prepareCall` captures an adapter registration; `adapterStream` is lazy, and later middleware may defer its iteration. A before-send check does not prove currentness at the actual provider call. The final request gate must check the exact owned execution, route, effective reasoning/output cap, current configuration/service/lifetime fences and empty tools when the owned stream is actually consumed. Delayed downstream middleware and captured old adapter generations are explicit counterexamples to test.
2. The public `markAgentLoopRequest` export records package-local request identity. It is callable by other plugins; `isAgentLoopRequest`, a `df-` prefix, a JSON session ID or a guessed digest alone is not owner authority. Use exact current private ownership, task/action/claim/generation/execution/session bindings and a one-use permit. An unowned ordinary native session, including an unowned similar prefix, must retain normal host behavior.
3. `AgentPresetRegistry` diagnostics explicitly await Host Loader settlement when rows are pending and warn against invocation inside a Host row's own activation. Awaiting those reads during the same installed entry's startup may wait on its own activation. Contract placement must resolve facts in a supported active operation rather than assert eager apply-time readiness. Future tests must include a genuinely pending public dependency, not only an already empty/settled preset.
4. JSONL's public configuration exposes `root` and `compression`; it exposes neither enforced retention nor a hard disk quota. Transcripts are plaintext when compressed. Any retention choice must be described as owner-managed or otherwise unsupported; no automatic deletion, global flush, second factory or plugin-local persistence shadow may be used to manufacture the guarantee. Its original factory captures the persistence service in the factory context. The public scoped durability seam is `SessionStore.flush(exactLiveSession):Promise<boolean>` using the stored session carrier; require successful listener participation and a persisted owned-log read. A raw `ctx.parallel('session/flush',...)`, backend roster/stat, returned `whenIdle()` or inaccessible private AgentHandle writer is not that barrier.
5. `maxTokens` is a per-request output cap. Native `contextWindow` describes combined request and response capacity; NI1's heuristic measures rendered text only. Separate these facts and measure all actual model-visible system/history/context text for the declared heuristic. Unknown model capacity must remain unknown, and a heuristic cannot accept BUB008-03's exact provider-token ceiling.
6. Current `RuntimeStore.claimAction` rejects `charges.costState:'unknown'`. The concrete contract preserves this gate: only the exact successfully registered, active product-owned deterministic implementation supplies source-bound synthetic zero external cost. Generic pricing remains unknown and refuses admission, even with an owner-selected zero monetary ceiling. Synthetic UTF-8 usage and estimated reservations remain separate from provider tokenization, currency billing or quality. Unknown usage/outcome from a previous action remains a real admission constraint.
7. The public approval policy `never` deterministically rejects approval asks; it does not grant tool use. The separate current tool-schema check and public invocation-time veto remain mandatory, including a late tool registration and a model-emitted tool call.

The concrete contract addresses these seven challenges at design level: explicit state2 operations avoid preset self-settlement; the original captured JSONL and scoped flush/read establish the intended persistence oracle; fixed scoped prompt/suppression and an exact two-message check constrain input; outer and inner lazy iterator gates cover late middleware and old registration; source-bound zero preserves the pricing gate; and empty-schema checks plus a monotonic invocation veto constrain tools. These are required future observations, not implementation findings already closed by tests. NI2 permits create only. Original resume and useful continuation are retained as later pending BUB004-03/BUB008 oracles.
