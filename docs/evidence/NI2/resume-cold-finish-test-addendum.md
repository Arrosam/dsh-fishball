## Exact request, trust and replay decision

Let `Q` be exactly `{taskRef,actionRef,claimRef,generationRef,executionRef,commandRef,expectedTaskVersion,expectedAuthEpoch}`. Six refs are lowerhex64; task version is a safe integer1..MAX_SAFE_INTEGER and auth epoch0..MAX_SAFE_INTEGER. Preserve ordinary closed descriptor/Proxy/prototype/canonical validation and input detachment. Public RPC never accepts `ownerRequest`, `finishRef`, receipt, evidence, usage, raw ID, handle, digest proof, scope or callback fields.

`readNormalNativeFinish(owner,Q)` uses a currently admitted scoped owner read capability. It returns only exact private `{receipt,finishRef}` or genuine `null`. It authenticates the mandatory six-kind normal-native registry, marked action, intent/origin/capture/finish and original command associations. It performs no mutation, clock update, native lookup/read/stop, new handle, provider, recovery, receipt-origin observation or capability creation. Reopening the actual store's existing validation/recovery is measured separately; the lookup's zero-write baseline starts after that authorized open completes. Constructor recovery cannot be mislabeled as lookup work or used to manufacture a finish.

The normal first-finish method retains exactly `{taskRef,commandRef,claimRef,generationRef,executionRef,captureRef,terminalEvidenceRef,outcomeEvidenceRef,usage}` and requires one additional `ownerRequest:Q`. `usage` retains the candidate actual-state/units shape. The opaque constructor-bound normal observer receives Q from the actual current owner operation. Core validates repeated task/command/claim/generation/execution refs and Q.actionRef against the signed action/capture, derives rather than accepts `ownerRequestDigest = H(['df.normal-native.finish-command/v1',ownerRef,workspaceRef,Q])`, and validates the full source graph and actual stop/usage/obligations. Existing canonical H is SHA256 of the established canonical encoding; it is not a new keyed algorithm.

Only `commandRef` and `ownerRequestDigest` are added to the candidate signed `normal_native_finish`; finishRef remains claimRef and every original field/domain remains. The matching keyed `runtime_commands` row has the original mutation principal/input digest, operation exactly `finishNormalNativeExecution`, same owner/workspace/task/command and private `{receipt,finishRef}` data. Settlement, signed finish, registry and command receipt share one original transaction. Do not call generic `settleAction` as a separately acknowledged transaction then append the marker. Authenticate both command→finish and finish→command, including the exact capture/action/execution/result/accounting association. No public normal-origin flag, unsigned response cache, legacy receipt, caller hash or equal generic body substitutes for those links.
