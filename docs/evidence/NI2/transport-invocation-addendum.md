# NI2 private current native invocation guard

Status: finding-driven internal source clarification; original wire, worker contract/design and advanced operation semantics remain unchanged. The frozen before/after-await native owner requirement cannot be implemented from a payload or a generic child-lifetime flag: the installed operation needs the exact admitted original peer and request AbortSignal at its mutation boundaries.

The bridge supplies one private immutable second operation argument, exactly `{assertCurrent}`. This function captures the original bridge lifetime, original connection, captured original OperatorPeer, actually admitted handler peer and native signal. It synchronously requires active bridge, literal true isAlive(), connection.operator===capturedPeer, admittedPeer===capturedPeer and signal not aborted. Failures use bounded SERVICE_DISPOSED, OPERATOR_REQUIRED or REQUEST_ABORTED; no raw exception, peer, signal, identity or capability enters RPC/config/output. The first argument remains the existing detached closed JSON input.

Calling assertCurrent opts that trusted operation invocation into a final bridge check after its await and before a successful response. Normal installed wrappers always call it before starting, after each asynchronous native/source/preview resolution and immediately before a store/native effect boundary, binding it to that invocation rather than a shared latest-request variable. If an internal manager awaits before claim, pass/capture that exact guard through its private current callback so the original final atomic permission check can narrow admission without recursive store reads or awaits. Concurrent policy previews never overwrite another request's guard. Retired/aborted callbacks cannot authorize replacement-lifetime work.

Legacy operation functions may ignore the second argument and retain their current already-started response behavior. In particular the unchanged operator-bridge test that aborts a legacy asynchronous operation after initial admission still returns its original detached value. A blanket unconditional post-await bridge rejection would violate that existing behavior and is not this clarification. No caller wire flag or command-name heuristic selects the mode; only trusted operation use of the closure opts in.

An abort/peer loss after an actual committed effect may prevent the normal success response but does not erase or repeat the authoritative receipt, grant, claim, stream or unknown reservation. Read-only reconciliation remains available under a current admitted invocation. Signal state is supplementary transport authority; original store grant/CAS/auth/control/current source/permission and native lifecycle predicates remain mandatory.

Required separate independent design before affected source GO: immutable exact private context and unchanged wire; zero callable payload access; before/after-await peer/signal/lifetime partitions; immediately-before-mutation and final original core permission guard; simultaneous independent invocations and no shared latest token; committed-before-abort uncertainty/no replay; legacy ignored-second-argument compatibility; bounded secret-safe errors. Actual native authenticated owner and physical package oracles remain separate from typed bridge doubles. No schema, new public capability, permission/account/credential or CODE/browser/release authorization is added.
