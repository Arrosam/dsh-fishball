This selects equivalence partitions and a three-by-three first-denial transition table, literal-true decision boundaries, reverse-completion asynchronous interleavings, captured-token identity/lifetime transitions, nested scope restoration and before-effect/commit-first outcomes. It does not mirror a seven-method facade, simulate native receipts as identity proof or create extra authorization from a status/read callback.

The helper's source-private token remains usable after an otherwise successful run only when deliberately captured and its original callback still admits. I10 covers that required delayed execution-gate behavior. Once denied, every use of that token retains the first bounded code even if the peer/lifetime double later recovers. New operations receive new carriers; they still require the real current source/core/native authority outside this helper.

`run()` reasserts after awaited method success **and caught failure**, so a wrapped source failure cannot override an already denied carrier. It performs0retries. In contrast `enter()` is an immediate source reentry primitive; async work must perform its own post-await check before an effect. I11 preserves that responsibility instead of inventing a stronger unimplemented promise. No modeled commit implies rollback, actual termination or slot release.

Guard exceptions are projected into bounded BootstrapError codes. The helper does not sanitize ordinary callback/domain exceptions when the guard remains current: I13 proves exact preservation. The bridge's separate final safe error projection must still occur before user output. No raw canary/exception was logged by these passing tests, and no ordinary accessor/coercion was invoked. Proxy descriptor reflection can execute once at this trusted error seam, is caught and never admits a callback; no Proxy authorization is claimed.
