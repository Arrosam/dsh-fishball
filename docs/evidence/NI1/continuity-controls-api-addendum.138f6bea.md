## 3. Status and acknowledgement literals

memoryStatus returns exactly `{state,revision,digest,updatedAt,reasonCode}`:

| Original source fact | Exact response values |
| --- | --- |
| Enabled current original getMemory returns null | state:'absent', revision:0, digest:null, updatedAt:null, reasonCode:null. |
| Authenticated live record | state:'live', positive original revision, original digest and updatedAt, reasonCode:null. |
| Authenticated deleted record, including empty encrypted content | state:'deleted', positive original revision, original retained digest and updatedAt, reasonCode:'MEMORY_DELETED'. |
| Disabled configuration | state:'unavailable', revision:null, digest:null, updatedAt:null, reasonCode:'MEMORY_DISABLED'. |

Wrong key/corrupt/unsupported/storage failure or lost invocation throws the exact safe failure; it must not return absent/deleted/unavailable as a substitute. getMemory's original AES/AAD verification is authoritative.
