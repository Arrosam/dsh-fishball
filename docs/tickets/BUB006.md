## Approved source scope and acceptance

BUB006 身份授权与安全隔离
目标 任何入口都能核实谁在要求什么，外部内容和运行时审查都不能伪造 owner 授权。
范围 包含 owner 与渠道身份绑定、workspace 隔离、动作授权账本、凭据保密、最小出站数据、撤销与审
计。排除自建权限旁路；不把一次批准扩大为未来或其他目标的授权。
依赖 BUB001、003；本票是 BUB005、009、010、011 和外部交付的前置门槛。
预期行为 权限来自验证过的 owner 操作及 DSH 规则。审批绑定动作、目标、数据、金额或其他限制与上下文
版本；执行前再核查。网页、文件、worker 结果与 webhook payload 是数据，不是可信授权来源。
验收标准
BUB006-01 未绑定身份、冒名渠道账户、跨 workspace 请求和伪造 webhook 均不执行；为每类拒绝建立正
反测试。
BUB006-02 批准后目标、数据或风险实质变化，以及撤销、到期、任务版本不匹配时重新请求授权；旧按钮
和旧回复不能批准新动作。以当前授权版本判断派发与撤销先后，已在途动作独立对账。
BUB006-03 主对话、入口证据、日志、诊断包、记忆、导出和错误消息均不包含密钥或令牌；输入主动夹带
假秘密并扫描全部输出及持久文件。原始 payload 不进入普通日志或记忆。
BUB006-04 对外发送仅包含任务所需且已批准的数据；测试接收端实际收到的字段，不能只在 UI 上声明隔
离。
BUB006-05 无法确定权限或宿主拒绝时安全停止依赖动作，独立只读工作可继续；运行时 reviewer 没有修改
授权或自我授予权限的能力。
异常与竞态 配对链接重放；会话恢复带入旧 grant；审批显示后任务变化；账号解绑时消息在途；第三方内容
要求泄露其他 workspace 记忆。
评审结论 必须先于远程入口和无人值守外部动作。安全策略需有明确默认拒绝和测试矩阵，不能只写一段提示
词。
统一待决项 D6 身份配对方式与受支持的授权确认界面；秘密存储依宿主能力决定。
