## Approved source scope and acceptance

BUB005 受控跨会话消息
目标 主对话、工作会话和独立审查会话能够交换需要的信息，不让任意会话读取或指挥其他任务。
范围 包含消息 broker、授权作用域、路由、关联、幂等、回执和可观测失败。排除默认开放所有会话互通；父
子通信能力不能当作无关 session 的通行证。
依赖 BUB003、004、006；输入上下文由 BUB008 控制，交付由 BUB013 控制。
预期行为 每条消息关联发送方、接收方、owner、workspace、task、消息 id、任务版本和用途。broker 从宿
主可信调用上下文核实发送方，不相信 payload 自报身份；按当前 grant 校验再派发。会话重建或标识复用不
继承旧 grant。
验收标准
BUB005-01 父子会话的状态回报可到达已授权父会话；无关会话未经明确 grant 发送消息时被拒绝，并留下
不含秘密的拒绝理由。
BUB005-02 grant 绑定任务或有界会话集合与消息类别；校验与派发记录绑定同一授权版本，定义撤销和派发
的先后判定点。撤销先发生则拒绝；已提交动作标为在途，不宣称撤回既成效果。
BUB005-03 按完整作用域和持久消息记录防止已知重复派发；消费状态未知时先核查，不盲目重发，不宣称
接收方 exactly once。乱序消息不能覆盖更高任务版本；无唯一 id 时明示降级。
BUB005-04 消息经过多个会话转发时保留原始来源和用途，并设置跳数或循环检测；出现循环时停止放大。
BUB005-05 accepted、已写入发件箱、sent、目标确认消费分别可见；超时只是状态未知或未确认，不自动
写成已送达。
异常与竞态 grant 撤销与发送竞态；session id 重用；向已结束会话发送；两个 owner 的任务 id 恰好相同；接
收方失联后重试。
评审结论 必须独立成票，不能隐含在工作会话工具中。建议默认只开任务内父子回报，跨任务消息作为显式有
界能力。
统一待决项 D5 首发允许的跨会话范围；消息保留期和超时后处理规则。
