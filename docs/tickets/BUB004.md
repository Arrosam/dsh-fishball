## Approved source scope and acceptance

BUB004 工作会话创建恢复与控制
目标 把明确的工作交给 DSH 会话，并知道它是否创建成功、准备就绪、正在执行或已经结束。
范围 包含创建、恢复、发送任务、查询当前状态、流事件、取消、结束和孤儿会话处理。排除另起 SDK 执行
栈；不要求上游没有公开提供的单会话关闭能力。
依赖 BUB001、003、006、008、011、012；状态回报接 BUB013。
预期行为 任务与会话映射持久保存。创建成功不等于开始执行；ready 后才派发。恢复既有会话前确认
owner、workspace、任务版本及宿主能力。取消用宿主真实接口，并通过事件或当前查询核实结果。
验收标准
BUB004-01 分别显示创建请求已受理、会话已创建、ready、执行中、结束或状态未知；每一步都有真实服务
响应或状态证据。
BUB004-02 创建超时但随后发现会话存在时，关联已有会话，不重复创建第二个执行者；无法判定时保持核
查态。
BUB004-03 恢复既有会话后执行一项可观察工作并得到产物；不存在或不属于当前授权范围的 session 不恢
复。
BUB004-04 取消请求与完成并发时，保留实际已完成效果与晚到结果；不宣称已经撤销外部发送、文件修改
等既成效果。
BUB004-05 事件流断开后通过当前查询与账本对账；重新订阅不会把历史事件当新任务，也不会丢失终态。
异常与竞态 宿主繁忙或模型未就绪；创建后插件重载；会话在取消前已经完成；用户手动关闭工作会话；恢复
到不同环境。
评审结论 可以实现，但每个宿主版本要验证具体服务能力。SDK 缺少 promptcancel 或 per-session close 不
等于原生插件一定缺少取消；反向推断同样不可用。
统一待决项 D1 基线接口；孤儿会话的自动回收范围和 owner 控制入口。
