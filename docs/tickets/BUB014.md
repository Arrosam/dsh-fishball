## Approved source scope and acceptance

BUB014 任务面板与用户控制
目标 owner 不必翻完对话就能了解任务状态、待批事项、工作会话和最后结果，并操作正确的任务。
范围 包含 DSH 内的任务列表与详情、状态来源、暂停继续取消、待用户决策、事件计划、审计和配置入口。排
除独立大应用与未验证的全实时控制台。
依赖 基础面板依赖 BUB001、003、004、006、013；事件与计划视图另依赖 009，远程交付状态另依赖 010。
入口使用真实宿主 UI 能力。
预期行为 面板从同一权威账本读取，显示更新时间和是否是快照；关键控制提交带任务版本。取消需要按真实
执行阶段反馈，暂停只保证不派发新工作，不能伪称已停止全部在途动作。
验收标准
BUB014-01 列表和详情对同一任务的状态、版本及阻塞一致；过时快照有时间标识，刷新会查询当前状态而
不是重画旧内容。
BUB014-02 对每个非终态提供适用控制；已完成、已取消、待审批和执行中任务的按钮符合状态转换合同。
BUB014-03 双击、旧页面和并发控制不会重复派发或覆盖新版本；错误提示解释失败与如何核查，不让 UI 自
行推断成功。
BUB014-04 真实 DSH UI 下检查窗口缩放、长中文、键盘操作、焦点、空列表、加载与错误状态；无截断关键
信息或遮挡操作。
BUB014-05 可直接查看任务相关会话、产物和授权范围；不展示凭据，不提供越权会话或其他 workspace 的
快捷入口。
异常与竞态 任务恰好结束时点击取消；插件重载后面板仍打开；网络或服务断开；大量任务；系统字体不同；
用户同时从远程修改。
评审结论 不能把面板放到发布前才补。建议先做朴素可用的列表和详情，功能与视觉都独立验收，避免把 UI 接
受点击误当控制生效。
统一待决项 D12 任务面板采用的宿主扩展入口；无该入口时的首发呈现方案需明示。
